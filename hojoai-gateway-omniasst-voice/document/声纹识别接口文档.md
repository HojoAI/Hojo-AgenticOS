# 声纹识别接口文档

## 接口概览

语音服务提供声纹识别相关的基础接口，用于处理音频文件并返回声纹向量。

### 接口列表

1. **声纹识别（JSON）** - `POST /omniasst-voice/v1/voiceprint/recognize`
2. **声纹识别（文件上传）** - `POST /omniasst-voice/v1/voiceprint/recognize/file`

---

## 接口详情

### 1. 声纹识别（JSON）

**接口路径**: `POST /omniasst-voice/v1/voiceprint/recognize`

**请求方式**: POST

**Content-Type**: `application/json`

**请求参数** (JSON):

| 参数名 | 类型 | 必填 | 说明 |
|--------|------|------|------|
| vid | String | 是 | 声纹识别ID |
| audio_length | Integer | 是 | Base64编码后的音频数据长度 |
| audio | String | 是 | Base64编码的PCM音频数据 |

**请求示例**:
```json
{
  "vid": "recognize-1234567890",
  "audio_length": 10240,
  "audio": "base64编码的PCM音频数据"
}
```

**响应格式**:

```json
{
  "resCode": "200",
  "resMessage": "success",
  "resContent": {
    "msg": "success",
    "rtn": 0,
    "vid": "recognize-1234567890",
    "voiceprint": "[0.277, 1.037, 1.280, ...]"
  }
}
```

**响应字段说明**:
- `resCode`: 响应代码，200表示成功
- `resMessage`: 响应消息
- `resContent.msg`: 算法服务返回的消息
- `resContent.rtn`: 算法服务返回码，0表示成功
- `resContent.vid`: 声纹识别ID
- `resContent.voiceprint`: 声纹向量JSON字符串，格式为数组字符串

**处理逻辑**:
1. 接收JSON请求参数
2. 调用算法API（VoiceprintAPI）进行声纹识别
3. 返回声纹识别结果

---

### 2. 声纹识别（文件上传）

**接口路径**: `POST /omniasst-voice/v1/voiceprint/recognize/file`

**请求方式**: POST

**Content-Type**: `multipart/form-data`

**请求参数** (FormData):

| 参数名 | 类型 | 必填 | 说明 |
|--------|------|------|------|
| file | File | 是 | WAV格式音频文件（最大10MB） |

**响应格式**:

```json
{
  "resCode": "200",
  "resMessage": "success",
  "resContent": {
    "msg": "success",
    "rtn": 0,
    "vid": "recognize-1234567890",
    "voiceprint": "[0.277, 1.037, 1.280, ...]"
  }
}
```

**错误响应**:
- 文件为空：`resCode: "ILLEGAL_ARGUMENT"`, `resMessage: "音频文件不能为空"`
- 文件过大：`resCode: "ILLEGAL_ARGUMENT"`, `resMessage: "文件大小超过限制，最大10MB"`
- 格式错误：`resCode: "ILLEGAL_ARGUMENT"`, `resMessage: "文件格式不正确，仅支持WAV格式"`
- 识别失败：`resCode: "GENERAL_ERROR"`, `resMessage: "声纹识别失败"`

**处理逻辑**:
1. 验证音频文件（格式、大小）
2. 将WAV文件转换为PCM格式（使用AudioConverter）
3. 将PCM数据转换为Base64编码
4. 构建VoiceprintRequest请求参数
5. 调用算法API（VoiceprintAPI）进行声纹识别
6. 返回声纹识别结果
7. 清理临时文件（WAV和PCM文件）

**请求示例**:
```bash
curl -X POST "http://host:port/omniasst-voice/v1/voiceprint/recognize/file" \
  -F "file=@/path/to/audio.wav"
```

## 通用说明

### 音频格式要求

**输入音频**:
- 格式：WAV
- 文件大小：最大10MB
- 转换后格式：PCM（16kHz采样率，16bit，单声道）

### 声纹向量格式

声纹向量以JSON字符串形式返回，格式为：`"[0.277, 1.037, 1.280, ...]"`

可以通过 `VoiceprintResponse.getVoiceprint()` 方法解析为 `double[]` 数组。

### 错误处理

所有接口在发生错误时会返回相应的错误信息：
- `ILLEGAL_ARGUMENT`: 参数错误（如文件为空、格式不正确、大小超限）
- `GENERAL_ERROR`: 通用错误（如声纹识别失败、文件处理失败）

---

## 注意事项

1. **文件上传接口**会自动处理音频格式转换，无需客户端预先转换
2. **临时文件**会在处理完成后自动清理
3. **声纹向量**维度通常为192维
4. 接口会记录关键日志：调用算法API的入参（vid, audioLength）和出参（rtn）
