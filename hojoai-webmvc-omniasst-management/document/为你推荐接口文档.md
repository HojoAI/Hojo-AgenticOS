# 为你推荐 - 接口与数据库文档

接口基础路径：`/omniasst-management/api/v0/recommendations`

---

## 一、推荐列表

### 1. 接口简介

查询当前用户的推荐内容。每种推荐类型（schedule / meeting / knowledge / explore）最多返回一条，取最新创建的有效推荐。自动排除已过期、已忽略、被抑制的类型。

### 2. 请求说明

| 名称 | 内容 |
|------|------|
| 接口地址 | /omniasst-management/api/v0/recommendations |
| 请求方式 | GET |
| Content-Type | - |

### 3. 请求参数

#### 3.1 Header 参数

| 参数 | 可选/必选 | 类型 | 说明 |
|------|-----------|------|------|
| X-User-Id | 必选 | String | 用户 ID |

#### 3.2 Query 参数

| 参数 | 可选/必选 | 类型 | 说明 |
|------|-----------|------|------|
| types | 可选 | String | 类型过滤，逗号分隔。如 `types=schedule,meeting`。不传则返回所有类型 |

### 4. 返回参数

| 参数 | 是否必返回 | 类型 | 说明 |
|------|------------|------|------|
| resCode | 是 | String | 状态码，成功为 OK |
| resMessage | 是 | String | 状态描述 |
| data | 是 | Array | 推荐列表，每种类型最多一条 |
| data[].recommendationId | 是 | String | 推荐 ID |
| data[].type | 是 | String | 推荐类型：schedule / meeting / knowledge / explore |
| data[].title | 是 | String | 类型标题（如"日程建议"） |
| data[].body | 否 | String | 建议话术 |
| data[].relatedId | 否 | String | 关联业务 ID |
| data[].relatedType | 否 | String | 关联业务类型 |
| data[].landingPage | 否 | String | 点击跳转路径 |
| data[].extra | 否 | Object | 类型特有的业务数据，前端按 type 解析（见下方各类型说明） |
| data[].attachments | 否 | Array | 文件附件列表 |
| data[].attachments[].name | 是 | String | 文件名 |
| data[].attachments[].size | 是 | Long | 文件大小（字节） |
| data[].attachments[].type | 是 | String | MIME 类型，如 image/png |
| data[].attachments[].thumbUrl | 否 | String | 缩略图地址（仅图片类型） |
| data[].attachments[].url | 是 | String | 文件 OSS 地址 |
| data[].createdAt | 是 | String | 创建时间 |
| data[].expiresAt | 否 | String | 过期时间，null 表示不过期 |

#### 各类型 extra 结构

**schedule（日程关联建议）**

| 字段 | 类型 | 说明 |
|------|------|------|
| scheduleTime | Long | 日程开始时间（毫秒时间戳） |
| scheduleEndTime | Long | 日程结束时间（毫秒时间戳） |
| scheduleTitle | String | 日程标题 |

> 日程关联的文档通过 `attachments` 字段返回，可能有多个。

**meeting（会议关联操作建议）**

| 字段 | 类型 | 说明 |
|------|------|------|
| minuteTitle | String | 纪要标题 |
| minuteId | String | 纪要 ID |
| eventType | String | 事件类型（如 meeting_minute） |

> 操作按钮由前端 UI 内置，后端不返回。

**knowledge（知识关联建议）**

无额外字段，关联文档通过 `attachments` 字段返回，可能有多个。

**explore（探索关联建议）**

| 字段 | 类型 | 说明 |
|------|------|------|
| researchTopic | String | 关联研究主题 |

> 操作按钮由前端 UI 内置，后端不返回。

## 二、忽略单条推荐

### 1. 接口简介

用户忽略一条推荐。后端标记该条为 ignored，并统计近 7 天该类型的忽略次数。累计达 3 次时，该类型被抑制 7 天（从第 3 次忽略时刻算起）。

### 2. 请求说明

| 名称 | 内容 |
|------|------|
| 接口地址 | /omniasst-management/api/v0/recommendations/{recommendationId}/ignore |
| 请求方式 | POST |
| Content-Type | - |

### 3. 请求参数

#### 3.1 Header 参数

| 参数 | 可选/必选 | 类型 | 说明 |
|------|-----------|------|------|
| X-User-Id | 必选 | String | 用户 ID |

#### 3.2 Path 参数

| 参数 | 可选/必选 | 类型 | 说明 |
|------|-----------|------|------|
| recommendationId | 必选 | String | 推荐 ID |

### 4. 返回参数

| 参数 | 是否必返回 | 类型 | 说明 |
|------|------------|------|------|
| resCode | 是 | String | 状态码，成功为 OK |
| resMessage | 是 | String | 状态描述 |

### 5. 请求&返回完整示例

#### 5.1 请求示例

```
POST /omniasst-management/api/v0/recommendations/REC1912345678901234/ignore
X-User-Id: 1234567890
```

#### 5.2 返回示例（成功）

```json
{
    "resCode": "OK",
    "resMessage": "成功"
}
```

## 三、创建推荐条目（内部接口）

### 1. 接口简介

供业务模块（日程、会议、知识库等）调用，向推荐表写入一条推荐。自动去重：同一 userId + type + relatedId 只允许一条 active 推荐，重复创建返回已有的 recommendationId。

### 2. 请求说明

| 名称 | 内容 |
|------|------|
| 接口地址 | /omniasst-management/api/v0/recommendations |
| 请求方式 | POST |
| Content-Type | application/json |

### 3. 请求参数

#### 3.1 Body 参数

| 参数 | 可选/必选 | 类型 | 说明 |
|------|-----------|------|------|
| userId | 必选 | String | 用户 ID |
| type | 必选 | String | schedule / meeting / knowledge / explore |
| title | 必选 | String | 类型标题 |
| body | 可选 | String | 建议话术 |
| relatedId | 可选 | String | 关联业务 ID |
| relatedType | 可选 | String | 关联业务类型 |
| landingPage | 可选 | String | 跳转路径 |
| extra | 可选 | Object | 类型特有的业务数据（JSON 对象，按类型自定义） |
| attachments | 可选 | Array | 文件附件列表 |
| attachments[].name | 必选 | String | 文件名 |
| attachments[].size | 必选 | Long | 文件大小（字节） |
| attachments[].type | 必选 | String | MIME 类型 |
| attachments[].thumbUrl | 可选 | String | 缩略图地址 |
| attachments[].url | 必选 | String | 文件 OSS 地址 |
| expiresAt | 可选 | Long | 过期时间（毫秒时间戳），不传则不过期 |

### 4. 返回参数

| 参数 | 是否必返回 | 类型 | 说明 |
|------|------------|------|------|
| resCode | 是 | String | 状态码，成功为 OK |
| resMessage | 是 | String | 状态描述 |
| data | 是 | String | 推荐 ID（如重复创建则返回已有的 ID） |

## 四、负反馈抑制规则说明

| 规则 | 说明 |
|------|------|
| 忽略统计窗口 | 近 7 天（滚动窗口） |
| 触发阈值 | 同一用户、同一类型，7 天内累计忽略 3 次 |
| 抑制时长 | 从第 3 次忽略时刻起，7 个自然日内不再返回该类型 |
| 抑制结束后 | 之前的忽略记录超出 7 天窗口，计数自然归零 |

## 五、DDL 建表语句

### pa_recommendation（推荐内容表）

```sql
CREATE TABLE pa_recommendation (
    id              BIGINT PRIMARY KEY AUTO_INCREMENT,
    recommendation_id VARCHAR(64)  NOT NULL COMMENT '业务主键',
    user_id         VARCHAR(64)  NOT NULL,
    type            VARCHAR(32)  NOT NULL COMMENT 'schedule/meeting/knowledge/explore',
    title           VARCHAR(256) NOT NULL DEFAULT '',
    body            VARCHAR(1024) DEFAULT NULL COMMENT '建议话术',
    related_id      VARCHAR(64)  DEFAULT NULL COMMENT '关联业务ID',
    related_type    VARCHAR(32)  DEFAULT NULL COMMENT '关联业务类型',
    landing_page    VARCHAR(512) DEFAULT NULL COMMENT '跳转路径',
    extra           TEXT         DEFAULT NULL COMMENT '类型特有业务数据(JSON)',
    attachments     TEXT         DEFAULT NULL COMMENT '文件附件列表(JSON数组)',
    status          VARCHAR(16)  NOT NULL DEFAULT 'active' COMMENT 'active/ignored/expired',
    created_at      DATETIME     NOT NULL DEFAULT CURRENT_TIMESTAMP,
    expires_at      DATETIME     DEFAULT NULL COMMENT '过期时间，NULL表示不过期',
    ignored_at      DATETIME     DEFAULT NULL COMMENT '忽略时间',
    UNIQUE KEY uk_recommendation_id (recommendation_id),
    KEY idx_user_status_expires (user_id, status, expires_at),
    KEY idx_user_type_related (user_id, type, related_id),
    KEY idx_user_type_ignored (user_id, type, status, ignored_at)
) COMMENT '为你推荐 - 推荐内容表';
```

### pa_recommendation_suppress（负反馈抑制表）

```sql
CREATE TABLE pa_recommendation_suppress (
    id               BIGINT PRIMARY KEY AUTO_INCREMENT,
    user_id          VARCHAR(64) NOT NULL,
    type             VARCHAR(32) NOT NULL COMMENT 'schedule/meeting/knowledge/explore',
    ignore_count     INT         NOT NULL DEFAULT 0 COMMENT '近7天忽略累计次数',
    suppressed_until DATETIME    DEFAULT NULL COMMENT '该类型在此时间前不推荐',
    created_at       DATETIME    NOT NULL DEFAULT CURRENT_TIMESTAMP,
    updated_at       DATETIME    NOT NULL DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP,
    UNIQUE KEY uk_user_type (user_id, type)
) COMMENT '为你推荐 - 负反馈抑制表';
```

## 六、推荐类型一览

| type | 说明 | 创建时机 | 主导模块 |
|------|------|----------|----------|
| schedule | 日程关联建议 | 日程开始前 X 分钟，且已关联知识库内容 | 日程模块 |
| meeting | 会议关联操作建议 | 纪要生成结束，识别到当前用户可能是主持人 | 会议模块 |
| knowledge | 知识关联建议 | 记忆有目标意图 + 知识库有匹配文档 | 知识/记忆模块 |
| explore | 探索关联建议 | 记忆有目标 + 目标在探索白名单 | 知识/记忆模块 |
