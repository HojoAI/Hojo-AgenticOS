# 语音翻译链路流程图

## 一、完整链路流程图

```mermaid
graph TB
    Start([客户端开始]) --> Connect[建立WebSocket连接]
    Connect --> Config[发送配置<br/>REQ_ASR_TRANSLATE_CONFIG]
    
    Config --> GetNacos[从Nacos获取语音服务实例]
    GetNacos --> ConnectVoice[连接语音服务WebSocket]
    ConnectVoice --> SendConfig[发送配置到语音服务<br/>target_languages: [lang1, lang2]]
    SendConfig --> InitChannels[语音服务初始化双通道]
    InitChannels --> ReturnChatId[返回chatId给客户端]
    
    ReturnChatId --> AudioLoop[开始音频处理循环]
    
    AudioLoop --> ReceiveAudio[接收音频数据<br/>REQ_TRANSLATE_AUDIO_DATA]
    ReceiveAudio --> Decode[解码Base64音频]
    Decode --> Forward[透传音频到语音服务<br/>不进行VAD检测]
    
    Forward --> VoiceBuffer[语音服务音频缓冲区]
    VoiceBuffer --> Split[音频分流]
    
    Split --> Channel1[通道1: 识别源语言]
    Split --> Channel2[通道2: 识别目标语言]
    
    Channel1 --> ASR1[ASR引擎1<br/>识别源语言]
    Channel2 --> ASR2[ASR引擎2<br/>识别目标语言]
    
    ASR1 --> Result1[识别结果1]
    ASR2 --> Result2[识别结果2]
    
    Result1 --> Detect[语种检测<br/>判断哪个通道有结果]
    Result2 --> Detect
    
    Detect --> Translate[翻译引擎<br/>根据检测语言翻译]
    Translate --> Combine[组合结果<br/>translations Map]
    
    Combine --> ReturnResult[返回结果<br/>BACK_ASR_TRANSLATE_RESULT]
    ReturnResult --> Map[结果映射<br/>确定原文/译文]
    
    Map --> SendClient[发送给客户端<br/>BACK_ASR_TEXT]
    SendClient --> CheckEnd{isEnd=1?}
    
    CheckEnd -->|否| AudioLoop
    CheckEnd -->|是| Publish[发布翻译结果]
    Publish --> Reset[重置运行时状态]
    Reset --> AudioLoop
    
    AudioLoop --> Stop{停止?}
    Stop -->|否| AudioLoop
    Stop -->|是| Close[关闭连接]
    Close --> End([结束])
    
    style Forward fill:#e1f5ff
    style VoiceBuffer fill:#fff4e1
    style Detect fill:#ffe1f5
    style Map fill:#e1ffe1
```

## 二、VAD处理流程

```mermaid
flowchart TD
    Start([音频数据]) --> CheckVAD{VAD处理位置}
    
    CheckVAD -->|客户端| ClientVAD[客户端VAD检测]
    CheckVAD -->|翻译服务| TranslateVAD[翻译服务VAD检测]
    CheckVAD -->|语音服务| VoiceVAD[语音服务VAD检测]
    
    ClientVAD -->|有效音频| Send[发送到翻译服务]
    TranslateVAD -->|当前实现: 跳过| Forward[直接透传]
    VoiceVAD -->|内部处理| Process[语音服务处理]
    
    Send --> Forward
    Forward --> Process
    
    Process --> ASR[ASR识别]
    
    style TranslateVAD fill:#ffcccc
    style Forward fill:#ccffcc
    note1[翻译服务不做VAD检测<br/>直接透传音频]
```

## 三、ASR双通道识别流程

```mermaid
sequenceDiagram
    participant Client as 客户端
    participant Translate as 翻译服务
    participant Voice as 语音服务
    participant Buffer as 音频缓冲区
    participant ASR1 as ASR通道1<br/>(源语言)
    participant ASR2 as ASR通道2<br/>(目标语言)
    participant Detect as 语种检测器
    
    Client->>Translate: 音频数据包1 (320ms)
    Translate->>Voice: 透传音频包1
    Voice->>Buffer: 累积音频
    
    Client->>Translate: 音频数据包2 (320ms)
    Translate->>Voice: 透传音频包2
    Voice->>Buffer: 累积音频
    
    Note over Buffer: 达到处理阈值或时间窗口
    
    par 并行识别
        Voice->>ASR1: 发送音频到通道1
        ASR1->>ASR1: 识别源语言
        ASR1-->>Voice: 识别结果1<br/>(可能为空)
    and
        Voice->>ASR2: 发送音频到通道2
        ASR2->>ASR2: 识别目标语言
        ASR2-->>Voice: 识别结果2<br/>(可能为空)
    end
    
    Voice->>Detect: 两个通道的识别结果
    Detect->>Detect: 判断哪个通道有有效结果
    Detect-->>Voice: detected_language
    
    Note over Voice: 根据detected_language<br/>确定原文和译文
```

## 四、翻译处理流程

```mermaid
flowchart TD
    Start([ASR识别结果]) --> GetResults[获取双通道结果]
    
    GetResults --> Check1{通道1有结果?}
    GetResults --> Check2{通道2有结果?}
    
    Check1 -->|是| Lang1[detected_language = 源语言]
    Check2 -->|是| Lang2[detected_language = 目标语言]
    
    Lang1 --> Trans1[翻译到目标语言]
    Lang2 --> Trans2[翻译到源语言]
    
    Trans1 --> Combine1[组合结果:<br/>原文=源语言文本<br/>译文=目标语言文本]
    Trans2 --> Combine2[组合结果:<br/>原文=目标语言文本<br/>译文=源语言文本]
    
    Combine1 --> Return[返回translations Map]
    Combine2 --> Return
    
    Return --> Format[格式化结果]
    Format --> Send[发送给翻译服务]
    
    style Lang1 fill:#e1f5ff
    style Lang2 fill:#fff4e1
    style Trans1 fill:#ffe1f5
    style Trans2 fill:#ffe1f5
```

## 五、结果映射流程

```mermaid
flowchart TD
    Start([收到语音服务结果]) --> Parse[解析结果]
    
    Parse --> GetTranslations[获取translations Map]
    Parse --> GetDetected[获取detected_language]
    
    GetTranslations --> SourceText[sourceLanguage文本]
    GetTranslations --> TargetText[targetLanguage文本]
    
    GetDetected --> Compare{detectedLanguage<br/>== sourceLanguage?}
    
    Compare -->|是| Normal[正常翻译模式]
    Compare -->|否| Reverse[反向翻译模式]
    
    Normal --> SetNormal[asrText = sourceText<br/>transText = targetText]
    Reverse --> SetReverse[asrText = targetText<br/>transText = sourceText]
    
    SetNormal --> Response[构建响应]
    SetReverse --> Response
    
    Response --> Send[发送BACK_ASR_TEXT]
    
    style Normal fill:#ccffcc
    style Reverse fill:#ffcccc
```

    Ch2 --> ASR2
    ASR1 --> Detect

    style Forward fill:#e1f5ff

## 七、时序图：完整处理流程

```mermaid
sequenceDiagram
    autonumber
    
    participant C as 客户端
    participant T as 翻译服务
    participant V as 语音服务
    participant A1 as ASR通道1
    participant A2 as ASR通道2
    participant E as 翻译引擎
    
    Note over C,E: 1. 配置阶段
    C->>T: REQ_ASR_TRANSLATE_CONFIG<br/>(source: chinese, target: english)
    T->>V: 建立WebSocket连接
    T->>V: REQ_ASR_TRANSLATE_CONFIG<br/>(target_languages: [chinese, english])
    V->>V: 初始化双通道识别器
    V-->>T: BACK_ASR_TRANSLATE_CONFIG_ACK
    T-->>C: BACK_CHAT_ID
    
    Note over C,E: 2. 音频处理阶段
    loop 持续发送音频包
        C->>T: REQ_TRANSLATE_AUDIO_DATA<br/>(Base64音频, 320ms)
        T->>T: 解码Base64
        Note over T: 不进行VAD检测<br/>直接透传
        T->>V: REQ_ASR_TRANSLATE_AUDIO_DATA<br/>(透传音频)
        
        V->>V: 累积到音频缓冲区
        
        alt 达到处理阈值
            par 并行识别
                V->>A1: 识别chinese
                A1->>A1: ASR处理
                A1-->>V: 结果1: "你好"
            and
                V->>A2: 识别english
                A2->>A2: ASR处理
                A2-->>V: 结果2: ""
            end
            
            V->>V: 语种检测<br/>detected_language = "chinese"
            V->>E: 翻译"你好" -> "Hello"
            E-->>V: 翻译结果
            
            V->>V: 组合结果<br/>translations = {<br/>  "chinese": "你好",<br/>  "english": "Hello"<br/>}
            
            V-->>T: BACK_ASR_TRANSLATE_RESULT<br/>(translations, detectedLanguage="chinese", isEnd=0)
            
            T->>T: 结果映射<br/>asrText = "你好"<br/>transText = "Hello"
            T-->>C: BACK_ASR_TEXT<br/>(text="你好", tranText="Hello", currLang="chinese", isEnd=0)
        end
    end
    
    Note over C,E: 3. 句子结束
    V-->>T: BACK_ASR_TRANSLATE_RESULT<br/>(isEnd=1)
    T->>T: 发布翻译结果
    T->>T: 重置运行时状态
    T-->>C: BACK_ASR_TEXT<br/>(isEnd=1)
```

## 八、关键决策点

```mermaid
flowchart TD
    Start([处理音频]) --> VAD{VAD检测?}
    
    VAD -->|翻译服务| Skip[跳过VAD<br/>直接透传]
    VAD -->|语音服务| Process[语音服务内部处理]
    
    Skip --> Process
    
    Process --> Split[音频分流]
    Split --> Ch1[通道1]
    Split --> Ch2[通道2]
    
    Ch1 --> Result1{有结果?}
    Ch2 --> Result2{有结果?}
    
    Result1 -->|是| Detect1[detectedLanguage = 源语言]
    Result2 -->|是| Detect2[detectedLanguage = 目标语言]
    
    Detect1 --> Map1[正常映射<br/>原文=源语言<br/>译文=目标语言]
    Detect2 --> Map2[反向映射<br/>原文=目标语言<br/>译文=源语言]
    
    Map1 --> Return[返回结果]
    Map2 --> Return
    
    style Skip fill:#ccffcc
    style Process fill:#fff4e1
    style Map1 fill:#e1f5ff
    style Map2 fill:#ffe1f5
```

## 九、错误处理流程

```mermaid
flowchart TD
    Start([处理流程]) --> Try[尝试处理]
    
    Try --> VADError{VAD错误?}
    Try --> ASRError{ASR错误?}
    Try --> TransError{翻译错误?}
    Try --> ProcessError{处理错误?}
    
    VADError -->|是| VADErr[VAD_ERROR]
    ASRError -->|是| ASRErr[ASR_ERROR]
    TransError -->|是| TransErr[TRANSLATE_ERROR]
    ProcessError -->|是| ProcessErr[PROCESS_ERROR]
    
    VADErr --> Handle[错误处理]
    ASRErr --> Handle
    TransErr --> Handle
    ProcessErr --> Handle
    
    Handle --> Log[记录日志]
    Log --> Send[发送BACK_ERROR]
    Send --> Client[返回给客户端]
    
    style VADErr fill:#ffcccc
    style ASRErr fill:#ffcccc
    style TransErr fill:#ffcccc
    style ProcessErr fill:#ffcccc
```
