- **Maven 坐标**：`com.microsoft.cognitiveservices.speech:client-sdk`
- **许可证**：Microsoft Software License Terms（**非** Apache-2.0 等开源许可证）
- **官方条款**：<https://aka.ms/csspeech/license>
- **Maven 元数据**：<https://repo1.maven.org/maven2/com/microsoft/cognitiveservices/speech/client-sdk/>
- **使用到的能力**：语音网关相关能力（如翻译、语音识别等，以实际代码为准）

**说明**：使用该 SDK 或分发包含该 SDK 的二进制产物时，须遵守微软许可条款；使用 Azure 语音等云服务时，还须遵守 **Azure 服务条款**及合规要求。

### 5.2 钉钉 RTC Linux Java SDK

- **Maven 坐标**：`com.ding.rtc.linux:ding-rtc-linux-java`（项目中曾使用版本如 `3.9.0`）
- **许可证**：一般为钉钉 / 开放平台提供的**专有许可或服务协议**，**非** Apache-2.0。在 Maven Central 公共仓库**未**检索到该坐标的发布件时，实际 JAR 多来自企业私服或钉钉官方分发渠道，**须以你获取 SDK 时附带的条款为准**。

**说明**：集成、再分发或向第三方交付包含该 SDK 的产物前，须从钉钉官方取得授权并遵守其许可与再分发要求。
