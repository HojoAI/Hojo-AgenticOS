## 2. 任务创建流程

```mermaid
sequenceDiagram
    participant Service as ScheduleServiceImpl
    participant Domain as ScheduleTaskDomainImpl
    participant Task as RedissonScheduledTask
    participant Runnable as ScheduleTaskRunnable
    participant Executor as RScheduledExecutorService
    participant Redis as Redis存储
    
    Service->>Task: 1. 创建任务对象<br/>设置taskType、scheduleId等
    Service->>Domain: 2. 调用scheduleAtFixedTime(task, targetTime)
    
    Domain->>Domain: 3. 计算延迟时间<br/>delayMillis = targetTime - now
    Domain->>Domain: 4. 验证时间有效性<br/>delayMillis >= 0
    
    Domain->>Task: 5. 设置executeTime
    Domain->>Runnable: 6. 创建ScheduleTaskRunnable<br/>(task, taskExecutor)
    
    Domain->>Executor: 7. executorService.schedule<br/>(runnable, delayMillis)
    
    Executor->>Redis: 8. 序列化任务对象<br/>存储到Redis队列
    Redis-->>Executor: 9. 返回taskId
    
    Executor-->>Domain: 10. 返回taskId
    Domain-->>Service: 11. 返回taskId
    
    Note over Redis: 任务在Redis中等待执行<br/>直到到达目标时间
```

## 3. 任务执行流程

```mermaid
sequenceDiagram
    participant Redis as Redis存储
    participant Executor as RScheduledExecutorService
    participant Runnable as ScheduleTaskRunnable
    participant TaskExecutor as ScheduleTaskExecutor
    participant Service as ScheduleServiceImpl
    
    Note over Redis: 到达执行时间
    
    Redis->>Executor: 1. 触发任务执行
    Executor->>Runnable: 2. 反序列化任务对象<br/>调用run()方法
    
    Runnable->>Runnable: 3. 检查taskExecutor<br/>是否为null
    
    alt taskExecutor为null
        Runnable->>Runnable: 4a. 从Spring容器获取<br/>或直接执行
    else taskExecutor不为null
        Runnable->>TaskExecutor: 4b. 调用executeTask(task)
    end
    
    TaskExecutor->>TaskExecutor: 5. 根据taskType判断<br/>任务类型
    
    alt SCHEDULE_REMINDER
        TaskExecutor->>Service: 6a. 执行日程提醒<br/>查询日程、发送推送
    else DAILY_BRIEFING
        TaskExecutor->>Service: 6b. 执行每日简报<br/>生成简报内容
    else SCHEDULE_CHECK
        TaskExecutor->>Service: 6c. 执行日程检查<br/>检测冲突
    else CUSTOM
        TaskExecutor->>Service: 6d. 执行自定义任务<br/>根据payload处理
    end
    
    TaskExecutor-->>Runnable: 7. 执行完成
    Runnable-->>Executor: 8. 任务执行结束
    Executor-->>Redis: 9. 更新任务状态
```

## 7. 完整任务管理流程图

```mermaid
flowchart TD
    Start([开始]) --> CreateTask[创建RedissonScheduledTask<br/>设置taskType、scheduleId等]
    
    CreateTask --> ValidateTime{验证执行时间<br/>targetTime >= now}
    ValidateTime -->|时间无效| Error1[抛出异常<br/>任务创建失败]
    ValidateTime -->|时间有效| CalcDelay[计算延迟时间<br/>delayMillis]
    
    CalcDelay --> CreateRunnable[创建ScheduleTaskRunnable<br/>包装任务对象]
    CreateRunnable --> SubmitTask[提交到RScheduledExecutorService<br/>schedule方法]
    
    SubmitTask --> StoreRedis[(存储到Redis<br/>序列化任务对象)]
    StoreRedis --> ReturnId[返回taskId]
    ReturnId --> Wait[等待执行时间]
    
    Wait --> CheckTime{到达执行时间?}
    CheckTime -->|否| Wait
    CheckTime -->|是| Deserialize[从Redis反序列化<br/>任务对象]
    
    Deserialize --> Execute[执行ScheduleTaskRunnable.run]
    Execute --> GetExecutor{获取TaskExecutor}
    
    GetExecutor -->|成功| RouteTask{根据taskType<br/>路由任务}
    GetExecutor -->|失败| DirectExec[直接执行任务逻辑]
    
    RouteTask -->|SCHEDULE_REMINDER| Reminder[执行日程提醒<br/>查询日程、发送推送]
    RouteTask -->|DAILY_BRIEFING| Briefing[执行每日简报<br/>生成简报内容]
    RouteTask -->|SCHEDULE_CHECK| Check[执行日程检查<br/>检测冲突]
    RouteTask -->|CUSTOM| Custom[执行自定义任务<br/>根据payload处理]
    
    Reminder --> Success[任务执行成功]
    Briefing --> Success
    Check --> Success
    Custom --> Success
    DirectExec --> Success
    
    Success --> UpdateStatus[更新任务状态]
    UpdateStatus --> End([结束])
    
    Error1 --> End
```

## 关键要点总结

### 1. 存储位置
- **Redis**: 所有任务存储在Redis中，通过Redisson的`RScheduledExecutorService`管理
- **执行器名称**: `"schedule-task-executor"`
- **持久化**: 任务序列化后存储在Redis队列中，服务重启不丢失

### 2. 任务创建
- 创建`RedissonScheduledTask`对象，设置任务属性
- 计算延迟时间（目标时间 - 当前时间）
- 创建`ScheduleTaskRunnable`包装任务
- 提交到`RScheduledExecutorService`，返回`taskId`

### 3. 任务执行
- Redis在到达执行时间时触发任务
- 反序列化`ScheduleTaskRunnable`对象
- 调用`run()`方法执行任务
- 根据`taskType`路由到不同的业务处理逻辑

### 4. 任务取消
- 通过`taskId`调用`cancelTask()`方法
- 从Redis队列中移除任务
- 已执行的任务无法取消

### 5. 分布式特性
- 多实例共享Redis中的任务队列
- 任务在任意可用实例上执行
- 支持高可用和负载均衡
