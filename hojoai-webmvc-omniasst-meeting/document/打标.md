# 会议场景 · 段落打标（offsetMs）

本文档与端云协议 **2.3.12 / 2.3.13** 及 **2.3.8 / 2.3.9** 中的 `isMark` 字段一致。连接方式、心跳、音频等见《会议场景 WebSocket 接口文档》。

---

## 1. 功能说明

- 端侧上报 **时间轴偏移** `offsetMs`（相对会议开始录制的毫秒数，与 ASR 时间轴一致），服务端将其映射到 **当前或历史某一段**（`segmentId`），并写入打标。
- 打标内容持久化至 `meeting_segments.mark_json`（与段落落库逻辑同前）。
- **两次成功打标**之间至少间隔 **5 秒**；否则返回 `BACK_MEETING_MARK_ACK` 失败形态（`code: TOO_CLOSE`），**不**写入数据。
- 下行 **`BACK_MEETING_ASR_TEXT`**、**`BACK_MEETING_SEGMENT_COMPLETE`** 中带 **`isMark`**：该 `segmentId` 是否已有打标。

---

## 2. 端侧发起打标（REQ_MEETING_MARK）

```json
{
  "event": "REQ_MEETING_MARK",
  "payload": {
    "pdata": {
      "offsetMs": 12350
    }
  }
}
```

| 参数名 | 类型 | 必填 | 说明 |
|--------|------|------|------|
| offsetMs | Long | 是 | 当前时间戳（相对会议开始录制的时间轴，毫秒），与产品文档 Current_Timestamp 对齐 |

---

## 3. 云侧返回（BACK_MEETING_MARK_ACK）

### 3.1 成功

```json
{
  "event": "BACK_MEETING_MARK_ACK",
  "payload": {
    "pdata": {
      "status": "success",
      "markId": "mark-1234567890",
      "message": "标记成功"
    }
  }
}
```

| 参数名 | 类型 | 说明 |
|--------|------|------|
| status | String | `success` |
| markId | String | 本次标记业务 ID |
| message | String | 提示文案 |

### 3.2 失败（间隔过近）

```json
{
  "event": "BACK_MEETING_MARK_ACK",
  "payload": {
    "pdata": {
      "status": "error",
      "code": "TOO_CLOSE",
      "message": "打标距离过近，请至少间隔5秒"
    }
  }
}
```

两次成功打标间隔 **&lt; 5 秒** 时返回；不更新 `mark_json`。

### 3.3 其它错误

参数非法（如缺少 `offsetMs`、`offsetMs` 无法映射到任一段落等）仍通过统一 **`BACK_ERROR`** 返回（见会议 WebSocket 文档）。

---

## 4. 服务端映射规则（offsetMs → 段落）

1. **已结束段落**：使用段完成时记录的 `[startTime, endTime]`（毫秒，相对会议时间轴）。`offsetMs` 落在区间内则命中该段。
2. **当前正在识别的一段**：`[lastSegmentEndTime, previousSendTime]`（累计音频时间轴）；略超出末尾时允许 **2 秒** 容忍，避免端上轻微超前。
3. 若仍不匹配：取时间轴上 **距离最近** 的一段；若最近距离 **&gt; 60 秒** 则视为非法，返回 `BACK_ERROR`。

持久化 JSON 示例（`mark_json`）：

```json
{
  "offsetMs": 12350,
  "markedAt": 1704067200000
}
```

---

## 5. 下行报文中的 isMark

### 5.1 BACK_MEETING_ASR_TEXT（2.3.8）

`pdata` 中增加：

| 参数名 | 类型 | 说明 |
|--------|------|------|
| isMark | Boolean | 当前 `segmentId` 是否已打标 |

### 5.2 BACK_MEETING_SEGMENT_COMPLETE（2.3.9）

`pdata` 中增加：

| 参数名 | 类型 | 说明 |
|--------|------|------|
| isMark | Boolean | 该段 `segmentId` 是否已打标 |

段结束后若用户再对该段打标，需依赖后续列表/详情接口刷新；实时流中在同一段未结束前打标后，下一条 ASR 推送会带 `isMark: true`。

---

## 6. 数据库

表 `meeting_segments` 字段 **`mark_json`**（TEXT），若尚无列：

```sql
ALTER TABLE meeting_segments ADD COLUMN mark_json TEXT;
```
