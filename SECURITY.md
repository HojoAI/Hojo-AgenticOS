# Security Policy

**Company / Rights Holder**: **HojoAI**.

## Supported Branches

| Branch / Tag | Receives Security Updates |
|--------------|--------------------------|
| `main`       | Yes                      |
| `develop`    | Yes                      |
| Other branches | Announced separately  |

## Reporting Vulnerabilities

**Do not** disclose unfixed high-risk vulnerabilities through public Issues.

Please send details to: **developer@hojoai.com** (subject line建议包含 `Hojo-Agentic-OS` and a brief description).

Your report should include:

- Affected version or branch and commit
- Reproduction steps and impact scope
- Fix approach if known

**HojoAI** will acknowledge receipt in a timely manner and coordinate remediation and disclosure. If you use [GitHub Private vulnerability reporting](https://docs.github.com/en/code-security/security-advisories/guidance-on-reporting-and-writing-information-about-vulnerabilities/privately-reporting-a-security-vulnerability) and the feature is enabled for this repository, you may also submit through that channel.
